# Protesis-mioelectrica-de-brazo
próyecto de protesis mioelectrica de brazo 
Se plantea que un brazo mioeléctrico puede detectar las señales eléctricas generadas por los músculos mediante un sensor EMG y utilizarlas para controlar un servomotor, permitiendo realizar movimientos mecánicos en respuesta a los movimientos de la mano y los dedos.
